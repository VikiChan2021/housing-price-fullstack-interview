# ADR-003：轻量状态与缓存

- 状态：Accepted
- 日期：2026-08-14

## 背景

原题要求估价历史和 Java 缓存，但没有用户账户、跨设备同步、数据库或分布式缓存要求。

## 决策

- Estimator 历史使用版本化 `localStorage`。
- Market 聚合缓存使用进程内 Caffeine，设置 TTL 和最大容量。
- V1 不引入数据库或 Redis。

## 理由

- 满足明确需求。
- 减少面试现场依赖和故障面。
- 保持实现可解释。

## 后果

- 历史仅在当前浏览器可用。
- 服务重启后缓存丢失。
- 如果未来增加登录、多实例或长期持久化，需要新的 ADR。
