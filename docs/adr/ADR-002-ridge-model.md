# ADR-002：回归模型

- 状态：Accepted
- 日期：2026-08-14

## 背景

数据只有 50 条，特征高度共线；原题要求简单回归、模型系数和性能指标。

## 决策

实现普通 LinearRegression baseline；首选交付模型为 `StandardScaler + Ridge`。正则化强度在训练折内选择，最终模型在全部训练数据重训。

## 理由

- Ridge 仍然简单且有系数。
- 比普通最小二乘更能缓解共线性导致的系数不稳定。
- 比树模型更符合 `/model-info` 的系数要求。

## 后果

- 必须说明系数处于标准化空间。
- 必须保存 scaler 参数和特征顺序。
- 模型信息不能把系数解释为因果效应。

## 未选方案

- 只用 LinearRegression：最简单，但系数可能不直观。
- Random Forest：可能有更好探索指标，但没有同等语义的线性系数。
