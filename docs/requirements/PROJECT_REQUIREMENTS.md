# 项目要求

## 1. 目标

构建、容器化并演示一个房价预测全栈系统。系统由一个独立模型服务、两个采用不同后端技术的业务应用和一个统一 Next.js 门户组成。

## 2. 用户角色

- 房产估价用户：输入单套或比较多套房产，查看预测价格和历史估价。
- 市场分析用户：浏览市场数据、筛选细分市场、进行 what-if 分析并导出结果。
- 面试官/评审者：从 GitHub 获取源码，通过文档一条命令启动，并在 Swagger 和浏览器中验证功能。

## 4. 非功能需求

以下是为保证可演示和可维护而增加的内部验收目标，并非面试官逐字规定：

- 本地冷启动应有清晰进度；所有容器健康后再开始演示。
- 模型服务暖机后的单次预测在本地开发机上目标为 1 秒内完成。
- API 必须有超时、结构化日志和一致错误格式。
- UI 必须支持桌面与移动视口，键盘可操作，表单错误可被辅助技术感知。
- 相同输入与相同模型版本应产生确定性预测。
- README 不得依赖作者 IDE 或未记录的本机配置。

## 5. 约束和假设

- 数据集是面试演示数据，不代表真实市场，不承诺商业准确性。
- 当前没有用户认证和多租户要求。
- 估价历史默认保存在浏览器 `localStorage`；清除浏览器数据后会丢失。
- 市场统计缓存默认采用进程内 Caffeine；重启 Java 服务后缓存清空。
- 公网部署是可选加分项，本地 Docker 演示是必须可靠完成的基线。
