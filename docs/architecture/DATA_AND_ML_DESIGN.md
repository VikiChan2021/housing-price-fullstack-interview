# 数据与模型设计

## 1. 数据画像

训练集：50 行，字段如下。

| 字段 | 类型 | 训练范围 | 模型用途 |
|---|---|---:|---|
| `id` | integer | 1~50 | 仅标识，排除 |
| `square_footage` | number | 980~2400 | 特征 |
| `bedrooms` | integer | 2~4 | 特征 |
| `bathrooms` | number | 1~3 | 特征 |
| `year_built` | integer | 1978~2012 | 特征 |
| `lot_size` | number | 4400~10500 | 特征 |
| `distance_to_city_center` | number | 2.1~8.2 | 特征 |
| `school_rating` | number | 6.5~9.1 | 特征 |
| `price` | number | 160000~410000 | 目标 |

待预测集：10 行，包含相同的 7 个特征，不含 `id` 与 `price`。

## 2. 已知数据特征

- 无缺失值、无重复行。
- 特征之间高度相关；例如面积和地块大小的相关性约为 0.992。
- 目标和多个特征都高度相关，数据看起来较规则且可能是合成数据。
- 普通最小二乘在高度共线数据上会产生不直观系数，因此系数不可解释为因果效应。
- 测试集中有轻微训练范围外输入：`year_built=2013`、`school_rating=9.2`、`distance_to_city_center=2.0`。

## 3. 输入校验策略

区分硬校验和模型范围警告：

- 硬校验：类型错误、空值、非有限数、负面积、负地块、评分不在 0~10、明显无效年份等返回 422。
- 范围警告：输入超出训练最小/最大值但仍具现实可能时允许预测，在响应中返回 `warnings`。
- 服务端以固定特征顺序构建数据，绝不依赖 JSON 属性顺序。

建议硬边界在实现前写入 schema 常量并测试，不能把训练范围直接当硬边界，否则题目自带预测数据会被错误拒绝。

## 4. 模型选择

### 基线

- `LinearRegression`。
- 用于证明最简单模型的效果和暴露多重共线性问题。

### 首选模型

- `Pipeline(StandardScaler, Ridge)`。
- 仍是简单、可返回系数的线性回归。
- 正则化比普通线性回归更适合高度相关特征。

不首选随机森林，即使探索指标可能更高，因为原题明确要求模型系数，而线性模型更容易解释和现场讨论。

## 5. 评估协议

为避免 50 条小数据的单次切分偶然性，固定以下唯一协议：

1. 全局随机种子为 `42`。
2. 外层使用 `KFold(n_splits=5, shuffle=True, random_state=42)`，报告泛化指标。
3. 每个外层训练折内使用 `KFold(n_splits=5, shuffle=True, random_state=42)` 选择 Ridge alpha。
4. alpha 候选固定为 `[0.01, 0.1, 1.0, 10.0, 100.0]`，以平均 RMSE 最小为选择规则；并列时选择较小 alpha。
5. `StandardScaler` 必须位于 Pipeline 内，确保每个训练折独立拟合，禁止在交叉验证前对全数据缩放。
6. 对外层每折记录 R²、MAE、RMSE，元数据报告均值和总体标准差（`ddof=0`）。
7. `LinearRegression` baseline 使用相同外层折，仅作对照，不参与 Ridge alpha 选择。
8. 外层评估结束后，在全部 50 行上用相同内层选择规则确定最终 alpha，并重训最终 Pipeline。
9. 对 10 条预测数据生成独立 `data/processed/test_predictions.csv`，但不伪造真实标签或测试指标。

不得因实现时间不足静默简化该协议。若确需改为固定 alpha，必须先新增替代 ADR、更新验收与元数据协议，并获得仓库所有者批准；调参用过的验证分数不得描述为独立测试成绩。

## 6. 模型产物

建议生成：

- `model.joblib`：完整 sklearn Pipeline。
- `metadata.json`：模型版本、算法、特征顺序、系数空间、scaler 参数、截距、训练数据 SHA-256、训练行数、评估协议、指标、依赖版本、训练时间。

模型版本格式固定为 `ridge-v1-<训练数据哈希前8位>-<训练配置哈希前8位>`。训练配置哈希至少覆盖特征顺序、随机种子、折数、alpha 网格、scikit-learn 版本和评估实现版本；训练时间不参与版本哈希。

二进制模型默认不提交 Git；Docker 构建或显式训练命令生成。`metadata.json` 可以提交，用于审阅变化。

## 7. 可复现性与版本

- 训练脚本读取 `utf-8-sig`。
- 训练前验证列集合、列顺序、行数、缺失值和数据哈希。
- 所有随机算法设置种子。
- 依赖版本写入 lockfile 和模型元数据。
- API 启动时校验模型的 `feature_names` 与服务 schema 一致。

## 8. `/model-info` 的系数语义

若使用 StandardScaler，默认返回标准化特征空间的系数，并明确：

- `coefficient_space: standardized`
- `feature_mean` 和 `feature_scale`
- 系数表示其他标准化特征不变时的模型变化，不表示因果关系。

如额外计算原始单位系数，必须通过测试确认转换公式和截距正确。

## 9. 模型限制

- 样本量极小，不代表真实城市市场。
- 特征共线严重，单个系数不稳定。
- 没有位置类别、装修、房屋状况、交易时间等真实关键变量。
- 范围外预测不可靠。
- 结果仅用于面试技术演示。
